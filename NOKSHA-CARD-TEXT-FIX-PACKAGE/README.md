# NOKSHA — Global Custom Merchandise Studio

A self-initiated global custom merchandise design-studio concept, developed by RAFEUL.

## Start here

1. Extract the ZIP.
2. Open `NOKSHA-standalone.html` or `index.html` in Chrome. Both files are self-contained and include the website styling, scripts and embedded product mockups.
3. No separate CSS, JavaScript or asset folders are required for the standalone build.

## Latest visual update

- Collection cards (Streetwear series, Minimal essentials, Graphic objects, Team & creator merch): title and subtitle are white, left-aligned and anchored bottom-left over the image.

See `previews/NOKSHA-CARD-TEXT-FIX.png` for the corrected card preview.

## Main features

- T-shirt, hoodie, cap and tote product mockups.
- Product colour, size, quantity and print-finish controls.
- Editable text layers, including English and Bangla text input.
- Artwork upload (PNG, JPG, WEBP, SVG).
- Add graphic and badge elements.
- Drag, resize, rotate, flip and adjust opacity.
- Front/back design surfaces, layer management, undo/redo.
- Mockup PNG export, transparent print-artwork PNG export, editable JSON save/load.
- Local demo cart and sample checkout.
- Global currency display and English/Bangla interface option.

## Important

NOKSHA is a portfolio concept prototype. Checkout is not connected to real payment or fulfilment. Customer notes shown in the concept are illustrative, not verified testimonials.
